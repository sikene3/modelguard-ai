> live activation and teardown, as recorded in `reports/phase-10.md`. The sensitive source, plan,
> receipt, inventory, and state-zero evidence was retained externally under encrypted, private

This directory records only the version-controlled, public-safe description of Phase 10 evidence.
No AWS response, GitHub response, Terraform plan or state, credential material, subscriber endpoint,
raw scanner output, vulnerability database, container archive, or generated runtime artifact belongs
here.

The browser-login dependency check and model-publisher tests are local evidence only. The former
imports the pinned CRT without contacting AWS. Publisher tests use injected in-memory S3/SSM doubles
for conditional creates, exact readback, lock contention, partial uploads, pointer failures, rollback,
and retained-lock fail closure. No model object or pointer was published live.

Local generated evidence remains ignored:

- `artifacts/security/sarif/`: sanitized scanner output;
- `artifacts/phase-07-evidence/build/`: local image metadata generated by the existing build helper;
- `artifacts/phase-07-evidence/trivy-*/`: local exact-image Trivy/CycloneDX output; and
- `artifacts/phase-10-evidence/local-runtime-remediation.json`: the atomic mode-0600
  `modelguard.runtime-contract-verification.v2` local-image-ID record.

The report at `reports/phase-10.md` records command results only after each gate executes. Following
the fail-closed Docker host reset, the baseline images were rebuilt with BuildKit and its private
generated evidence was sealed under the approved durable Phase 10 backup root. The remediation
candidate was rebuilt again from its exact lock, scanned by immutable local image ID, accepted by the
sealed verifier with AppArmor, built-in seccomp, and genuine `no-new-privileges`, and passed the full
Compose smoke/demo/E2E matrix. Its generated evidence remains ignored locally and is intentionally
not copied into this version-controlled directory.

Local image-ID evidence does not by itself set Terraform `runtime_contract_verified=true`; any
future authorized activation must supply a matching clean-source immutable-registry-digest record.
Historical live ECS, IAM, S3, SSM, CloudWatch, Logs, SNS, Firehose, OIDC, budget, CloudTrail,
Terraform, and teardown acceptance rests on the externally retained private attestation described
above, not on local tests or files in this directory.
